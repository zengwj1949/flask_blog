# 一、项目概述
flask_blog：这是一个用 Flask 框架开发的博客项目。

博客系统应该包含几个基本模块
1、认证登陆模块，如登陆、注册、退出等，可以作为一个单独的蓝图；
   - 登陆为单独的视图函数；
   - 注册为单独的视图函数；
   - 退出为单独的视图函数；
   
2、博客模块，如对博客数据的增、删、改、查等，可以作为一个单独的蓝图；
   - 增，创建新的博客内容，单独的视图函数实现；
   - 删，删除已存在的博客内容，单独的视图函数实现；
   - 改，修改已存在的博客内容，单独的视图函数实现；
   - 查，打开博客首页或打开指定的博客内容，需要查询数据库数据或缓存再进行加载，单独的视图函数实现；
